# گپ‌خونه ۲.۰

پیام‌رسان گروهی و خصوصی با رابط فارسی واکنش‌گرا (قابل استفاده در موبایل و دسکتاپ/PWA)، ثبت‌نام و ورود، CAPTCHA تصویری، پروفایل، عکس پروفایل، پایگاه داده و ارتباط زنده WebSocket.

## اجرای محلی

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

سپس `http://127.0.0.1:8000` را باز کنید.

## انتشار در Render

1. کل محتویات این پوشه را در یک مخزن GitHub آپلود کنید (فایل ZIP را داخل مخزن آپلود نکنید؛ ابتدا Extract کنید).
2. در Render گزینه New + → Blueprint را انتخاب و مخزن را متصل کنید تا `render.yaml` خوانده شود.
3. Render سرویس وب و PostgreSQL را می‌سازد. برای پلن‌های پولی ممکن است هزینه داشته باشد؛ قبل از تأیید قیمت را بررسی کنید.
4. پس از Deploy، آدرس سرویس را باز کنید.

اگر سرویس را به‌صورت دستی می‌سازید:
- Build: `pip install -r requirements.txt`
- Start: `uvicorn main:app --host 0.0.0.0 --port $PORT`
- متغیر `APP_SECRET` را به یک مقدار تصادفی و محرمانه تغییر دهید.
- برای ماندگاری داده‌ها PostgreSQL متصل کنید؛ SQLite روی دیسک موقت سرویس مناسب انتشار نیست.

## نکات مهم قبل از استفاده عمومی

این نسخه یک پایه کاربردی و قابل توسعه است، نه جایگزین کامل واتساپ. CAPTCHA در حافظه سرور نگهداری می‌شود و برای چند نمونه هم‌زمان باید به Redis منتقل شود. برای مقیاس‌پذیری WebSocket چندسروری نیز Redis Pub/Sub لازم است. محدودسازی نرخ درخواست، تأیید ایمیل/شماره، مدیریت گزارش و مسدودسازی، ارسال فایل امن، رسید تحویل/خواندن، اعلان Push و رمزنگاری سرتاسری هنوز پیاده‌سازی نشده‌اند. پیام‌ها در پایگاه داده ذخیره می‌شوند اما رمزنگاری سرتاسری ندارند. قبل از استفاده عمومی و داده حساس، بازبینی امنیتی لازم است.
